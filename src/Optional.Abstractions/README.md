# Toarnbeike.Optional.Abstractions

**Toarnbeike.Optional.Abstractions** contains the core abstractions of the [Toarnbeike.Optional](https://github.com/Toarnbeike/Toarnbeike.Optional) library. [![Nuget](https://img.shields.io/nuget/v/Toarnbeike.Optional.svg)](https://www.nuget.org/packages/Toarnbeike.Optional)

It provides these abstractions as a `netstandard2.0` project, making it suitable for use in source generators and other scenarios where dependencies on newer .NET versions are not possible or desirable.

For more information regarding the full library, see the [main README](../../README.md).
